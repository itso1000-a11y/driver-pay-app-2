# Driver Pay App Full PWA

This archive restores the full React/TypeScript app and adds PWA install support:
- public/manifest.json
- public/icon.svg
- public/sw.js
- index.html service worker registration

Deploy:
1. Upload all files to GitHub.
2. Commit changes.
3. Vercel will redeploy.
4. Open the site in Chrome on Android and check Install app.
